# 工位窒息指数

一个原创的职场自测小工具。给 10 个职场日常场景各挑一个发生频率，浏览器当场算出 0–100 的「窒息指数」，给出五档结论、毒舌点评和保命建议，并生成一张可保存转发的海报。

> 打工人吐槽向：毒舌但不刻薄，结论海报供自嘲与传播，不当证据用。

## 功能亮点

- **10 道场景题**：微管理、沟通失灵、加班文化、偏心、粉饰太平、功劳被吞、情怀打压、边界失守、办公室政治、成长停滞。
- **5 级频率**：从不 / 很少 / 有时 / 经常 / 总是。
- **5 档结论**：0–20 / 21–40 / 41–60 / 61–80 / 81–100。
- **实时指针仪表**：答题时即时联动，只显示分数、不出结论；结论页再次读数。
- **可保存海报**：9:16 PNG，带编号、日期与一句裂变文案，一键存图。
- **零依赖 / 零上传**：单文件 HTML，原生 CSS + 原生 JS，离线双击即可运行；所有计算在浏览器端完成。
- **URL 分享**：10 个答案编码进链接 hash，打开即还原同一结果，无需服务器。

## 安装

把本技能装进本地 WorkBuddy 技能库：

```bash
bash scripts/install_local.sh .
```

装完后即可在 WorkBuddy 中触发使用（例如说「做个职场窒息自测」「生成职场吐槽测评网页」）。

## 使用

1. 把 `assets/quiz.html` 复制到当前工作区（默认文件名 `quiz.html`）。
2. 用 WorkBuddy 的预览打开，直接使用。
3. 如需改题、改配色、加维度或导出，在 `assets/quiz.html` 的代码基础上调整，并同步更新本技能里的副本。
